Надоело самому высчитывать unix timestamp для дискорда. Давно надо было сделать программу.

Одноэкранная программа.

- Поля ввода времени (Д Ч М С)
- Поле вывода штампа времени с кнопкой копирования в буфер.

Второй экран с настройками. Не хочу всё пихать на один экран.
- UI scale
- Theme selector
